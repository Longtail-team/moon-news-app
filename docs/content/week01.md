# 1주차 지문

- 제목: RM Opens His Art Collection to the World
- 난이도: 약 780L (추정치. 화면에는 "난이도"로 표기)
- 본문 단어 수: 173 (제목 제외)
- 음원: 아직 없음. 숫자(178, 142, 36), "RM x SFMOMA"의 x, SFMOMA를 음원에서 어떻게 읽는지 정해지면 여기에 적는다.

규칙
- 영어 원문 글자는 바꾸지 않고 끊어 읽기 위치에만 " / "를 넣는다. 정렬할 때는 " / "를 뺀다.
- 7단어 이하 짧은 문장은 끊지 않는다. 한국어는 문장 단위로 하이라이트한다.
- 영어 1문장 = 한국어 1문장으로 맞춘다.
