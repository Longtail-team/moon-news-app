## 2026-10-09 · 기사 음원은 청독에서만 (`feat/audio-in-listening`)

- 한국어·영어 기사 읽기 화면에서 영어 기사 음원·한영 구간반복 재생을 빼고 "음원은 청독에서 들어요 ›" 링크로. 화면 구성(듣기 → 낭독 → 확인)은 그대로
- VOCA 구간반복은 문장이 아니라 청독으로 보지 않음 → 청독 화면에서 빼고 VOCA 탭(작성·단어 낭독)에 그대로, 청독량에도 넣지 않음
- 청독량 = 청독 화면 + 이번 주 자료에서 들은 영어 기사 음원·한영 구간반복
- **콘텐츠 시트 시범 반영**: 1기 시트 1주차 상태 "초안" → "공개", GitHub Actions "콘텐츠 시트 반영"(검사만 → 반영) 정상. 앱 1주차 지문이 시트 13문장으로, 듣기 전 질문 카드 표시. 2주차는 초안이라 숨김(샘플 2주차 자리표시 기사도 함께 숨겨짐)
- **청독 화면에 지문과 청독 하이라이트**(spec 8장): 영어 기사 음원은 끊어 읽기 구, 한영 구간반복은 한국어 문장 → 영어 문장 2회 순서로 칠함(예상 시간 비율). 끊어 읽기 표시·영어만 보기. 지문 표시는 `ArticleText`로 기사 읽기와 함께 씀

### T03 접속 링크·세션 + 학생 홈 (PR #3)
- `/a/<토큰>` → 해시 확인 → 세션 쿠키(원문 미저장) → 링크 없는 주소로 이동. 보호자 링크 = 자녀 전부(형제 프로필 고르기), 자녀 링크 = 본인
- 홈: 주차 카드, 오늘 학습하기, 종강·완주 진행, 12주 기록(펼침), 라이브 카드, 하단 탭
- 임시 적용: 링크 여러 번 사용, 세션 180일, 새 링크 보내도 이전 링크 유지. 다시 들어가기(인증번호)는 개강 후. 결제 직후 데이터 구조(결정 5)는 첫 접속 작업 때

### 낭독 화면 (PR #4)
- 활동 선택(요일 추천, 지난 주차, 작성 중·이어서) → 1 듣기 → 2 낭독(3초 카운트다운, 하이라이트, 30초 전 안내, 5분 자동 정지) → 3 확인 → 완료

### 작성 활동 + 인스타 올리기 (PR #5)
