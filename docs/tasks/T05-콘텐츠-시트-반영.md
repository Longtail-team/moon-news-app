# T05 콘텐츠 시트 → 앱 반영 (설계안)

기준: spec.md 17장(학습 자료 운영), 16장(학습 자료 테이블)  
상태: **설계안. 아래 "결정 필요"가 정해지면 구현한다.**

## 1. 목표
운영자가 콘텐츠 시트에 주차별 기사·문장·단어·파일·링크·안내를 미리 입력해 두면, 앱에 반영되고 **각 주차가 시작되는 월요일 0시에 그 주차 자료가 열린다.**  
학생 앱은 시트를 직접 읽지 않고 DB·Storage에서만 읽는다(spec 17장).

## 2. 순차적으로 열리는 방법 (이미 구현됨)
- 자료는 미리 반영해 둔다. 앱은 **주차 시작 시각(cohort_weeks.starts_at, 월 0시 KST)이 지나고 기사 상태가 "공개"**일 때만 보여 준다.
- 그래서 운영자가 12주치를 한 번에 반영해도 학생에게는 한 주씩 열린다. 검수가 덜 된 주차는 상태를 "초안"으로 두면 시작일이 와도 "자료를 준비하고 있어요"로 보인다.
- 이번 주 자료 탭은 열린 주차만 고를 수 있고, 다음 주차가 열리는 날을 안내한다.

## 3. 시트 구성 (제안)

| 탭 | 한 행 = | 열 |
|---|---|---|
| 기수 | 기수 1개 | 과정명, 기수, 시작일(월), 종강일(12주차 일), 보상 PDF 파일명 |
| 주차 | 기수의 주차 1개 | 기수, 주차, 기사 ID |
| 기사 | 기사 1개 | 기사 ID, 영어 제목, 한국어 제목, 난이도, 단어 수, 상태(초안/검수완료/공개), 기사 PDF, VOCA PDF, 영어 음원, 한영 구간반복, VOCA 구간반복, 인스타 템플릿 (각 파일명) |
| 문장 | 문장 1개 | 기사 ID, 문단, 문장, 영어(끊어 읽기 " / "), 한국어 |
| 단어 | 단어 1개 | 기사 ID, 번호, 단어, 뜻, 예문 |
| 추가 자료 | 링크·안내 1개 | 기사 ID, 순서, 종류(링크/안내), 제목, 링크(https), 내용 |
| 라이브 | 라이브 1회 | 기수, 회차, 일시, 줌 링크, 다시보기 링크 |

- 파일은 약속된 드라이브 폴더에 두고 시트에는 **파일명**만 쓴다. 반영할 때 Storage로 복사한다(드라이브 공유 링크를 재생에 쓰지 않는다, spec 17장).
- 기사는 기수와 분리한다. 다음 기수에서 같은 기사를 쓰면 "주차" 탭만 새로 쓴다.
- 추가 자료(링크·안내)는 기사에 붙는다(다음 기수에도 그대로 쓰임). DB `week_items`에 이미 자리가 있다.

## 4. 반영 전 검사 (spec 17장)
빈 문단, 영어·한국어 중 한쪽만 있는 문장, 폴더에 없는 파일, 공개일이 됐는데 "공개"가 아닌 기사, https가 아닌 링크, 음원 규격(MP3/AAC). 문제가 있으면 **반영하지 않고** 목록으로 보여 준다.

## 5. 결정 필요: 시트와 앱을 잇는 방법

| | A. 시트에서 앱으로 보내기 (추천) | B. 앱이 시트를 읽어 오기 |
|---|---|---|
| 방식 | 시트에 앱스 스크립트 메뉴 "앱에 반영" → 검사 → 앱 서버로 전송(비밀 키), 파일은 서버가 준 업로드 주소로 Storage에 직접 올림 | 앱 서버가 구글 서비스 계정으로 시트·드라이브를 읽음. 관리자 화면 "자료 반영" 버튼 + 매일 자동 |
| 준비 | 시트에 스크립트 붙이기, 앱 쪽 비밀 키 1개 | 구글 클라우드 프로젝트·서비스 계정 만들기, 시트·폴더를 서비스 계정에 공유 |
| 장점 | 구글 클라우드 설정이 필요 없음. 운영자가 시트에서 바로 반영하고 결과(오류 목록)를 시트에서 봄 | 반영 기록·오류가 관리자 화면에 모임. 자동 반영 가능 |
| 단점 | 자동 반영은 시트 시간 트리거로 따로 설정 | 처음 설정이 번거로움 |

- 시트를 "웹에 게시(CSV)"로 공개해 읽는 방법은 쓰지 않는다. 유료 자료(기사 원문·해석)가 공개된다.

## 6. 결정되면 구현할 것
- 반영 API(서버): 검사 → 기사·문장·단어·추가 자료·기수·주차·라이브 upsert, 파일 업로드 주소 발급, 파일이 바뀌면 새 version
- (A) 시트 앱스 스크립트: 메뉴, 검사, 전송, 결과를 "반영 기록" 탭에 남김 / (B) 서비스 계정 연결과 관리자 버튼
- 테스트: 검사 규칙, 반영 결과, 주차 시작 전에는 학생 화면에 안 보이는지
