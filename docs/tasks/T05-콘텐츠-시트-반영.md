# T05 콘텐츠 시트 → 앱 반영 (설계안)

기준: spec.md 17장(학습 자료 운영), 16장(학습 자료 테이블)  
상태: **구현됨(2026-10-08)** — `.github/workflows/content-sync.yml` + `scripts/sync-content.mjs` + `lib/content/parse.mjs` + DB `sync_week`·`sync_live`·`sync_asset_state`, 기록 `sync_runs`

## 1. 목표
운영자가 콘텐츠 시트에 주차별 기사·문장·단어·파일·링크·안내를 미리 입력해 두면, 앱에 반영되고 **각 주차가 시작되는 월요일 0시에 그 주차 자료가 열린다.**  
학생 앱은 시트를 직접 읽지 않고 DB·Storage에서만 읽는다(spec 17장).

## 2. 순차적으로 열리는 방법 (이미 구현됨)
- 자료는 미리 반영해 둔다. 앱은 **주차 시작 시각(cohort_weeks.starts_at, 월 0시 KST)이 지나고 기사 상태가 "공개"**일 때만 보여 준다.
- 그래서 운영자가 12주치를 한 번에 반영해도 학생에게는 한 주씩 열린다. 검수가 덜 된 주차는 상태를 "초안"으로 두면 시작일이 와도 "자료를 준비하고 있어요"로 보인다.
- 이번 주 자료 탭은 열린 주차만 고를 수 있고, 다음 주차가 열리는 날을 안내한다.

## 3. 시트 구성 (2026-10-08 정리 완료)

시트: [새벽달 영어뉴스 1기 콘텐츠 시트](https://docs.google.com/spreadsheets/d/1Pkt4uPnv59n-j65_yXteETNCVlx8wR6B0RTlaOAFAEw/edit) — **기수마다 시트 1개**, 주차 = 그 기수의 주차(1~12).

| 탭 | 한 행 = | 열 |
|---|---|---|
| 기사 | 주차 1개 | 주차, 영어 제목, 부제, 한국어 제목, 단어 수, 렉사일, AR, 상태(초안/검수완료/공개, 드롭다운), 자료 PDF, 영어 음원, 한영 구간반복, VOCA 구간반복, 인스타 템플릿(파일명), 메모 |
| 문장 | 문장 1개 | 주차, 문단, 문장, 영어(끊어 읽기 " / "), 한국어, 검수 메모 |
| 단어 | 단어 1개 | 주차, 번호, 단어, 뜻, 예문 |
| 추가 자료 | 링크·안내 1개 | 주차, 순서, 종류(링크/안내, 드롭다운), 제목, 링크(https), 내용 |
| 라이브 | 라이브 1회 | 회차, 일시, 줌 링크, 다시보기 링크 |
| 작성 안내 | — | 운영자용 규칙(끊어 읽기 기준 포함) |
| 원본(정리 전) | — | 정리 전 백업. 반영하지 않음 |

- 정리 때 기존 "제목"(제목 / 부제)을 두 칸으로 나눴고, 문단 통째 본문을 문장 탭으로 옮겼다. 문장을 " / " 빼고 다시 이으면 원본 본문과 글자 단위로 같음을 확인했다.
- 끊어 읽기는 1주차 지문 규칙을 따른다: 7단어 이하 짧은 문장은 끊지 않음, 쉼표 뒤·전치사구·접속사 앞·인용문과 "RM said" 사이에서 끊음, 줄표(—)·하이픈·고유명사·따옴표 안쪽에서는 끊지 않음.
- 반영 구현 때 DB에 `articles.subtitle`(부제), `articles.ar_level`(AR)을 추가한다.
- 기수·주차 일정(시작일, 종강일)은 시트가 아니라 관리자 쪽에서 정한다(기수 생성 시 cohort_weeks 12주 자동).
- 파일은 약속된 드라이브 폴더에 두고 시트에는 파일명만 쓴다. 반영할 때 Storage로 복사한다(드라이브 공유 링크를 재생에 쓰지 않는다, spec 17장).
- 추가 자료(링크·안내)는 기사에 붙는다. DB `week_items`에 이미 자리가 있다.

## 4. 반영 전 검사 (spec 17장)
빈 문단, 영어·한국어 중 한쪽만 있는 문장, 폴더에 없는 파일, 공개일이 됐는데 "공개"가 아닌 기사, https가 아닌 링크, 음원 규격(MP3/AAC). 문제가 있으면 **반영하지 않고** 목록으로 보여 준다.

## 5. 보안 설계 (2026-10-08 검토: 보안 최우선)

### 지켜야 할 것
1. **브라우저(개발자 도구)에 구글 관련 정보가 전혀 가지 않는다.** 시트 ID, 드라이브 링크, 키, 토큰 모두 서버에만 있다. 학생 화면은 DB 값과 앱 주소(`/files/…`)만 받는다.
2. **아직 열리지 않은 주차 내용은 브라우저로 보내지 않는다.** 미리 반영해 둔 기사·자료도 주차 시작 전에는 화면 데이터에 싣지 않는다. (2026-10-08 수정 완료: 홈 12주 기록의 미래 주차 제목 제거, 학습 자료 파일은 `/files` 경로가 수강·주차 공개를 확인한 뒤 1분짜리 주소로 보냄)
3. **유출될 키를 만들지 않는다.** 시트를 읽는 권한은 오래 사는 비밀 키 파일 대신 짧게 쓰고 사라지는 토큰으로 얻는다.
4. **최소 권한**: 시트와 자료 폴더는 "보기"로만 공유한다. 앱은 시트를 고칠 수 없다.
5. 반영은 서버에서만 실행하고, 누가 언제 반영했는지 기록을 남긴다.

### 방법 비교

| | B-1. 앱이 읽기 + 키 없는 연결 **(추천)** | B-2. 앱이 읽기 + 서비스 계정 키 | A. 시트에서 앱으로 보내기 |
|---|---|---|---|
| 자격 | Vercel이 실행 때마다 발급하는 신원 토큰 → 구글이 확인 후 1시간짜리 토큰 (Workload Identity Federation) | 서비스 계정 JSON 키를 Vercel 환경변수에 저장 | 공유 비밀 키를 앱스 스크립트 속성에 저장 |
| 유출 위험 | **저장된 키가 없다.** Vercel 이 프로젝트 밖에서는 토큰을 받을 수 없다 | 키가 새면 누구나 시트를 읽을 수 있다(교체 전까지) | 시트 편집 권한자는 스크립트를 열어 키를 볼 수 있다. 스크립트가 운영자 계정의 넓은 드라이브 권한으로 실행된다 |
| 권한 | 전용 서비스 계정, 시트·폴더 보기만 | 같음 | 운영자 계정 권한 |
| 처음 설정 | 구글 클라우드 프로젝트 + 신원 연결 설정 (안내 따라 30분 정도) | 구글 클라우드 프로젝트 + 키 발급 | 시트에 스크립트 붙이기 |

- 시트를 "웹에 게시(CSV)"로 읽는 방법은 쓰지 않는다(유료 자료가 공개된다).

**추천: B-1 (확인 필요).** 반영 실행은 ① 관리자 화면 "자료 반영" 버튼(관리자 로그인 필요, 관리자 작업과 함께) ② 매일 새벽 자동(Vercel Cron, 비밀 헤더 확인) 두 가지로 한다. 관리자 화면 전까지는 ②와 서버에서만 실행하는 명령으로 쓴다.

### 사람이 할 일 (B-1 설정, 구글 계정 필요)
1. 구글 클라우드 콘솔에서 프로젝트를 만들고 Google Sheets API, Google Drive API를 켠다(무료).
2. 서비스 계정을 하나 만든다(키는 만들지 않는다).
3. Workload Identity 풀을 만들고 Vercel(팀 `id-9548s-projects`, 프로젝트 `moon-news-app`)을 신원 공급자로 연결한다. 연결 값은 작업 때 정확히 안내한다.
4. 콘텐츠 시트와 자료 폴더를 그 서비스 계정 이메일에 **"보기"로 공유**한다.

## 8. 운영 방법 (구현 후)
- **수동 실행**: GitHub 저장소 → Actions → "콘텐츠 시트 반영" → Run workflow. "검사만 하고 반영하지 않기"(기본 켜짐)를 끄면 실제로 반영한다.
- **매일 자동(새벽 3시)**: 저장소 설정 → Secrets and variables → Actions → Variables에 `CONTENT_SYNC_ENABLED` = `true`를 만들면 켜진다. 처음에는 꺼 둔다(시트의 1·2주차가 초안이라, 켜면 샘플 학습자에게서 1·2주차가 숨겨진다).
- **결과**: 실행 기록(Actions 로그)에 주차별 반영/안 함, 오류(✕)·경고(!)가 행 번호와 함께 나온다. "공개" 주차에 오류가 있으면 그 주차는 이전 상태를 유지하고 실행이 실패로 끝나 GitHub가 알림 메일을 보낸다. DB `sync_runs`에도 남는다(관리자 화면에서 볼 예정).
- **기수 폴더**(2026-10-08): 기수마다 폴더 하나(`게시 자료/1기`, `2기` …)에 그 기수의 시트와 파일을 모두 둔다. `content_sources.folder_id`는 기수 폴더를 가리킨다.
- **파일명 규칙**(2026-10-08): 기수 폴더 한 곳에 `news<기수 2자리>_week<주차 2자리>_<종류>.<확장자>`로 넣는다. 종류: `pdf`(주차 자료 PDF) / `article`(영어 기사 음원) / `kren`(한영 구간반복) / `voca`(VOCA 구간반복) / `tem`(인스타 템플릿). 예: `news01_week01_voca.mp3`. 규칙대로면 시트 파일 칸은 비워도 자동 연결되고, 칸에 이름을 쓰면 그 파일이 우선한다. 규칙과 비슷하지만 틀린 이름은 경고한다. 구글 문서·시트 파일은 조용히 건너뛴다.
- **파일**: 기사 탭 파일 칸의 이름으로 자료 폴더(하위 폴더 포함)에서 찾는다. 같은 파일(md5)이면 다시 올리지 않고, 바뀌면 새 경로·새 version으로 연결만 바꾼다. 구글 문서 형식(시트·문서)은 반영하지 않는다.
- **로컬 검사**: `node --env-file=.env.local scripts/sync-content.mjs --dry-run --fixture <시트 값 JSON>`
